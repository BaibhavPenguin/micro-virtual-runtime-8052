# View Buffers on Micro Virtual - R AT89S52

The `buf` command is used for viewing the system state on Micro virtual - R on AT89S52.

`buf flag`

The `flag` refers to an access flag for viewing a specific buffer.

### **Operands Supported**
`-r` : View **result** buffer  
`-i` : view **input** bufer  
`-o` : view **output** buffer
