# Bitwise AND on Micro Virtual - R AT89S52

Micro Virtual - R Supports Logical AND via the `and` command.

## **Usage**

`and data1 data2` 

Takes two 8-bit decimal operands, performs data1 **AND** data2 , They are numbers between 0-255  

<br>
<br>

`and data1`

The operand is a single 8-bit decimal, Pefrorms Operand **AND** the previous result, 

<br>

## **Other Information**
The `and` command does not support negative numbers and/or hexadecimal numbers. using hexadecimal numbers may result in undefined behaviour and system crashes.
