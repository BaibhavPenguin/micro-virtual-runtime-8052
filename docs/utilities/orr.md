# Bitwise OR on Micro Virtual - R AT89S52

Micro Virtual - R Supports Logical OR via the `orr` command.

## **Usage**

`orr data1 data2` 

Takes two 8-bit decimal Operands, performs data1 **OR** data2 , They are numbers between 0-255  

<br>
<br>

`orr data1`

The operand is an 8-bit decimal, Pefrorms Operand **OR** the previous result, 

<br>

## **Other Information**
The `orr` command does not support negative numbers and/or hexadecimal numbers. using hexadecimal numbers may result in undefined behaviour and system crashes.
