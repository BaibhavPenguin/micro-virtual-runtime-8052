# Bitwise XOR on Micro Virtual - R AT89S52

Micro Virtual - R Supports Logical XOR via the `xor` command and give sthe remainder.

## **Usage**

`xor data1 data2` 

Takes two 8-bit decimal Operands, performs data1 **XOR** data2 , They are numbers between 0-255  

<br>
<br>

`xor data1`

The operand is an 8-bit decimal, Pefrorms Operand **XOR** the previous result, 

<br>

## **Other Information**
The `xor` command does not support negative numbers and/or hexadecimal numbers. using hexadecimal numbers may result in undefined behaviour and system crashes.
