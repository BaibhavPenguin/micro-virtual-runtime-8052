# Load Buffer on Micro Virtual - R AT89S52

Loading the result buffer witha 16_bit value is directly possible via the `rld` command.

## Usage
`rld data16`

The `rld` command takes a single  decimal operand from 0 to 65535. It loads the Virtual Accumulator for further procesing and arithmetic or logocal operations.
