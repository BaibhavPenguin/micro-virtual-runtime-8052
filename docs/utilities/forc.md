# Previlliges on Micro Virtual - R AT89S52
Micro virtual - R blocks the access to potentially dangerous commands by default however, the can be enabled via the `--f` command.

The `--f` command toggles the fail_safe mechanism and enables partial access to system reserved resources.  
Commands run under disabled fail safe may cause total system failure and require an external reset.  
Use at your own risk!
