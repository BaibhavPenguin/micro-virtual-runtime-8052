# Bitwise NOT on Micro Virtual - R AT89S52

Micro Virtual - R Supports Logical NOT via the `not` command.

## **Usage**

`not data1`

Gives the 1's Compliment of a 16-bit operand (0-65535)

<br>

## **Other Information**
The `not` command does not support negative numbers and/or hexadecimal numbers. using hexadecimal numbers may result in undefined behaviour and system crashes.
