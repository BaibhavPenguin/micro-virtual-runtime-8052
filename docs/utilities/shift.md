# **Bitwise Left Shift on Micro Virtual - R AT89S52**

Micro Virtual - R Supports Bitwise Left Shift via the `shift` command.

## **Usage**

`shift left count data` 

Shift `data` towrads the left by 1 bit for `count` times.
`data` can be a 16-Bit Number

<br>
<br>

`shift left count`

Shift the contents of the 16-Bit virtual Accumulator towards the left by 1 bit for count times.

<br>


# **Bitwise Right Shift on Micro Virtual - R AT89S52**

Micro Virtual - R Supports Bitwise Right Shift via the `shift` command.

## **Usage**

`shift right count data` 

Shift `data` towrads the right by 1 bit for `count` times.
`data` can be a 16-Bit Number

<br>
<br>

`shift right count`

Shift the contents of the 16-Bit virtual Accumulator towards the right by 1 bit for count times.

<br>




# **Other Information**
The `shift` command does not support negative numbers and/or hexadecimal numbers. using hexadecimal numbers may result in undefined behaviour and system crashes.
