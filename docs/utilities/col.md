# Terminal Text Color on Micro Virtual - R AT89S52

VArious terminal colors are supported in Micro virtual - R for AT89S52


## **Command**

`--c short_code`

the `--c` command with a color shortcode can be used to change the terminal color. Micro Virtual - R supports 8 Colors , namely

<table>

<tr>
<th> Color Code
<th> Color
</tr>

<tr>
<td> 00
<td> Black
</tr>

<tr>
<td> 01 
<td> Red
</tr>

<tr>
<td> 02
<td> Green
</tr>

<tr>
<td> 03
<td> Yellow
</tr>

<tr>
<td> 04
<td> Blue
</tr>

<tr>
<td> 05
<td> Magenta
</tr>

<tr>
<td> 06
<td> Cyan
</tr>

<tr>
<td> 07
<td> White
</tr>
</table>
<br>

Operands other than listed shortcodes are strictly rejected.



# **Other Information**
These commands are system commands and play no role in Logical and Arithmetic Operations. however, some dangerous operations are prevented by other system commands.
