**PuTTY Terminal is Recomemded for use with Micro Virtual-R**

`Serial Baud Rate : 9600` <br>
`Terminal Type : xterm-256`<br>
`Backspace Key : "Ctrl + ?" (Decimal = 127)`<br>
`Flow Control : None`<br>
`Parity : None`<br>
`Stop Bits : 1`<br>
`Data Bits : 8`<br>
