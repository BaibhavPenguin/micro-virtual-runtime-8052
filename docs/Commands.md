<h1><strong>Supported Commands in Micro Virtual-R for At89S52</strong></h1>
<br>

**Clear Screen "cls"**
`cls`
<br>
**Reset Command Line "-cl"**
`-cl`
<br>
**Runtime Software Reset "--r"**
`--r`
<br>
**Change Text Color "--c"**
<br>
`--c color_short_code`

**Colors Supported Are**
`00 = black`<br>
`01 = red`<br>
`02 = green`<br>
`03 = yellow`<br>
`04 = blue`<br>
`05 = magenta`<br>
`06 = cyan`<br>
`07 = white`

**Default Color is set to white**
