<h1><strong>Supported Commands in Micro Virtual-R for At89S52</strong></h1>
<br>

**Clear Screen "cls"** <br>
`cls`
<br>
**Reset Command Line "-cl"** <br> 
`-cl`
<br>
**Runtime Software Reset "--r"**  <br>
`--r`
<br>
**Change Text Color "--c"**  <br>
<br>
`--c color_short_code`
 
**Colors Supported Are**  <br>
`00 = black`<br>
`01 = red`<br>
`02 = green`<br>
`03 = yellow`<br>
`04 = blue`<br>
`05 = magenta`<br>
`06 = cyan`<br>
`07 = white`

**Default Color is set to white**
